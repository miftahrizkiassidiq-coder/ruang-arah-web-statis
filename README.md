# Ruang Arah — Halaman Masuk

Project latihan UTS Pemrograman Web Statis.

## File
- `index.html`: struktur dan elemen halaman masuk.
- `style.css`: warna, layout, dan tampilan responsif.

## Cara menjalankan
Buka `index.html` di browser. Pastikan `style.css` berada di folder yang sama.

## Catatan
Ini adalah antarmuka statis. Tombol Google, pemulihan kata sandi, dan pendaftaran belum terhubung ke layanan sungguhan.
